dev.factory

A shared software factory where teams and AI agents turn product work into governed, reviewable changes.

Connect a project to its GitHub repository, shape the work into a Flow, then let agents take on repeatable development tasks in the cloud. People stay in control of the decisions and the code that moves forward.

From project to pull request

A repeatable path from idea to reviewed code.

Each Project owns its repository connection and Flows. A Flow defines when work starts, which steps the Agent follows, and the guardrails around each run.

01 / CONNECT

Project + repository

Bring a software project and its GitHub repository into one shared team workspace.

02 / DEFINE

Flow + know-how

Shape repeatable work with triggers, ordered steps, model choices and project-specific instructions.

03 / RUN

Agent in the cloud

Agents work in isolated Azure Container Apps Jobs, using an environment built for the repository.

04 / REVIEW

People stay in control

Review the proposed changes. A human approval comes before Flow steps that write back to GitHub.

05 / LEARN

Track each run

Follow its status, result, duration and model cost in the Project's activity history.

Designed around the team

Governed work, in a shared cloud workspace.

01 / CLOUD EXECUTION

Free the workstation

Automated Agent runs execute in Azure Container Apps Jobs, so a developer's machine does not need to stay online to do the work.

02 / GOVERNANCE

Guardrails in the Flow

Set a spend limit for each Flow Run and require human approval before a step writes changes to GitHub.

03 / PROJECT KNOW-HOW

Instructions travel with the work

Give Agent steps project-specific instructions today. Deeper shared project memory and reusable team knowledge are in development.

04 / MODEL CHOICE

Many models, one workflow

The current prototype connects through OpenRouter, giving teams a choice of models from multiple providers. Direct connections to more providers are still in development.

05 / COST VISIBILITY

Know what each run costs

Model usage and cost are recorded for each run and associated with its Project. Project-wide budgets and consolidated spend reporting are planned.

06 / REPRODUCIBLE SETUP

Work in the project's environment

Build Agent runs around the repository's declared development environment, helping the team reduce setup differences between machines.

In active development. The prototype already supports Project Flows, Agent runs, cloud execution, human approvals and per-run spend limits. Shared project memory, direct provider integrations and Project-wide spend controls are still evolving.

dev.factory is a private project. This overview describes its direction and current capabilities; source code and internal configuration are not published here.
