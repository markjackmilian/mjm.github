mjm.cleaner

A tool for finding and removing regenerable temporary files on your Mac. See what will be removed before you decide.

How it works

A clear path from scan to confirmation.

01 / SCAN

Choose what to check

Select the categories and start a read-only scan. Nothing is deleted during analysis.

02 / REVIEW

See the preview

Before removal, the app shows the exact paths and sizes of the items it found.

03 / DECIDE

Confirm the cleanup

Cleanup starts only after your explicit confirmation. A summary follows when it is done.

mjm.cleaner is a macOS project. Technical details and source code are available in its GitHub repository.
